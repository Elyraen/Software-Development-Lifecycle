## Sprint Review & Retrospective Reflection

### Interpreting User Needs and User Stories

Interpreting user needs starts with understanding what the user is trying to achieve rather than just what features they request. In the SNHU Travel project, this was done through stakeholder feedback and translating that input into user stories. User stories helped break down requirements into simple, actionable goals from the user’s perspective, such as browsing popular travel destinations.

Creating user stories made the development process more focused because each feature had a clear purpose and acceptance criteria. This ensured that the development team was not just building features, but building functionality that directly improved the user experience.

### My Approach to Developing Programs and Agile Practices

I approach program development by first breaking the system into smaller components and understanding how they interact. During this project, Agile practices such as sprint planning, daily scrums, and backlog refinement helped structure the development process and keep progress consistent.

In future development work, I plan to continue using Agile practices like:
- Iterative development through short sprints  
- Regular communication through daily stand-ups  
- Backlog prioritization and refinement  
- Continuous feedback from stakeholders  

These practices help ensure that development stays aligned with user needs while remaining flexible to change.

### What It Means to Be a Good Team Member

Being a good team member in software development means actively communicating, staying accountable, and contributing to shared goals. In an Agile environment, this includes participating in meetings, being open to feedback, and supporting other team members when challenges arise.

It also means being adaptable. Since requirements can change, a strong team member is someone who can adjust their work while still maintaining quality. Collaboration and consistency are critical, because even one person falling behind or not communicating can impact the entire team’s progress.
